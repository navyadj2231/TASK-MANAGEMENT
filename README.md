# Task Management Project

A full task management system built using HTML, CSS, JavaScript, and Node.js with in-memory storage. 
Includes user signup/login, admin & user roles, and complete task CRUD features.

## Features
- Signup & Login
- Role-based access (Admin/User)
- Add / Edit / Delete tasks
- Search, Sort, Filter tasks
- Pagination
- Internal memory database (no MongoDB)
